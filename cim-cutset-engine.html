Modelling assumptions — confirm these
  • CONFIRM AGAINST SINGLE-LINE. The edges below are illustrative. They deliberately funnel both catcher buses through one ATS (AMCOP) and one breaker (CUPP-MBP) so the engine reveals a found single point of failure on first run.
  • Illustrative edges: MEDS_1/MEDS_2/GEN_1/GEN_2 → AMCOP; AMCOP → CUPP-MBP; CUPP-MBP → CUPS & CUPP-XFMR (parallel); CUPS → BUS_1.1C & BUS_2.1C; CUPP-XFMR → BUS_1.1C & BUS_2.1C; BUS_1.1C & BUS_2.1C → COP.
  • DLB simplification: DLB load-shed (DAC/LAC) / generator protection is modelled as a commissioned node with no power-path edges — it does not gate COP supply in this graph, so it never appears in a cut set. If DLB mis-operation can actually trip the supply, add the appropriate edge and re-run.
  • GENAN is passive switchgear furniture (commissioned:false) — excluded as a fault candidate and treated as always-up structure; shown off the power path.
  • Locked facts: COP is fed only by the catcher buses BUS_1.1C / BUS_2.1C and survives if ≥1 is live. BUS_2.1C also feeds every MEDS lifeboat tap. CUPP-MBP feeds CUPS and CUPP-XFMR in parallel. AMCOP passes power if it is up and any input source reaches it. This is the B-side critical-path model.
  • Candidates: fault candidates = nodes with commissioned:true, excluding the load itself (the load failing is not a supply-path cut). Minimal cut sets are enumerated to order 3.
